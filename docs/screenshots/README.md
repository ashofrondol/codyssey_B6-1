## 2026-10-29 현재 들어 있는 것

| 파일 | 무엇인가 | 주소창 포함? |
| --- | --- | --- |
| `01-browser.png` | `http://3.38.94.117/` 의 실제 페이지(`Hello Cloud`)를 **헤드리스 Chromium 으로 캡처** | ❌ 없음 |
| `02-health.png` | `http://3.38.94.117/health` 의 실제 응답 본문(`OK`) 같은 방식으로 캡처 | ❌ 없음 |

두 장 모두 **실제 서버 응답을 그대로 찍은 것**이다(그림을 만들거나 합성하지 않았다).
다만 헤드리스 브라우저에는 주소창·탭이 없어서 **어느 IP 에 접속했는지 이미지만으로는 안 보인다.**
그래서 URL·상태 코드·요구사항 ID 판정은 [`../verification.txt`](../verification.txt) 가 맡는다
(그 파일에 `B6-1-X2 http://3.38.94.117/ → 200`, `B6-1-X3 GET /health → 200 "OK"` 가 그대로 있다).

**주소창이 보이는 캡처로 대체하려면** — 본인 PC 브라우저에서 `http://3.38.94.117/` 를 열고 캡처해
`01-browser.png` 를 덮어쓰면 된다(터미널 캡처는 `02-health.png`). 정리(`99_cleanup.sh`) 후에는 주소가 사라지므로 그 전에 한다.

## 캡처할 때

- **주소창과 응답 코드가 같이 보이게** 찍는다. 페이지 본문만 있으면 어느 서버인지 알 수 없다.
- 계정 ID, 액세스 키, 이메일은 가린다. 퍼블릭 IP 는 정리 후 회수되므로 가리지 않아도 된다.
- 터미널 캡처 대신 텍스트를 남겨도 된다 —
  `bash infra/04_verify.sh | tee docs/verification.txt` 가 같은 내용을 파일로 만든다.
